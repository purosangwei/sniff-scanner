    What it looks for

    The tricks

    The ways fake-recruiter tests get code onto your machine.

    • Code that runs on npm install. The Binance attack worked like this: the test ran its payload during setup.
    • VS Code tasks that run when you open the folder. No install needed, just opening it is enough.
    • Hidden and scrambled code. Obfuscators, long encoded blobs, eval, code pushed off the edge of the screen.
    • Calls home. Bare IP addresses, paste sites, Discord and Telegram webhooks.
    • Hunting for your stuff. MetaMask and Phantom, saved browser passwords, SSH keys.
    • Dodgy packages. Lookalike names, packages days old, packages npm has taken down.
    • Files that don't belong. Programs, native add-ons, code dressed up as fonts, hidden orders for AI assistants.
    • The repo itself. Brand-new repos and accounts, one-commit histories.

    1Scan first

    Before you install anything or open the folder in VS Code. Both can run code on their own.

    2Use a throwaway machine

    A VM or cloud dev box, never the laptop with your wallets or work logins. Even when the scan comes back clean.

    3Check the company

    A real website that links to the same GitHub account. Recruiters who rush you to run the test are a warning sign in themselves.
